# 2026-10-15 (목) — PowerPoint 자동종료 후보

검증용 빌드에서 인덱싱을 위해 직접 실행한 PowerPoint가 비어 있으면 정상종료를 요청한다.
사용자 문서·보호된 보기·슬라이드 쇼가 있거나 실행 주체를 확인하지 못하면 보존한다.
PowerPoint 강제종료는 사용하지 않으며, 종료 요청과 실제 프로세스 종료를 구분한다.

문서 처리 완료·사이클 종료·기존 주기 재기동에서 같은 호스트에 중복 요청하지 않는다.
기존 방식으로 연결한 인스턴스에는 종료 권한을 부여하지 않는다. 실행/종료 결과가 불명확하면
새 워커에서도 중복 실행을 막고, 정상 저장된 인덱싱 결과는 그대로 유지한다.

reader와 setup 요구 버전은 **1.0.2.0**, 서비스 규약은 **3**이다. 추출 JSON schema 1과
청크·인덱스 형식은 유지하므로 이 변경만으로 전체 재인덱싱하지 않는다.

## 시험 빌드

```bat
build.bat clean candidate
```

결과는 `dist/candidate/AegisDesk`에 생성된다. 자동종료는 후보에서만 시험하며 기본·소스·released는
비활성이다. 자동 설치와 자동종료의 활성화 범위는 별개다. 사용자 설정이나 환경변수로 켜지 않는다.

## 실제 환경 검증

Windows 빌드·.NET 컴파일·Office의 직접 실행 연결·취소 이벤트 ABI·Quit 콜백 순서는
현재 환경에서 실행하지 않았다. [검증 절차](../guides/PPT_READER.md#powerpoint-자동종료-후보-검증)에
따라 사용자 문서 보존과 실제 종료를 확인해야 한다. 자동 검사가 통과해도 이 시험을 대신하지 않는다.
정상종료의 일반 배포 활성화는 실제 검증 결과에 따른 별도 변경이다.
