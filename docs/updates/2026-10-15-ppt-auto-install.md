# 2026-10-15 (목) — PowerPoint 자동 설치 후보

검증용 빌드에서 앱이 설치 확인, Windows 권한 요청, 추가 기능 등록, 설치 후 재확인을 이어서 처리한다.
사용자는 DLL 등록 명령을 입력할 필요가 없다. 명시적 권한 거절만 기억하며 일시적인 점유나
설치 실패는 다음 실행에서 재평가한다. 설치 종료를 확인하지 못하면 준비 대기를 유지한다.

요구 버전은 1.0.1.0이며 기본 빌드는 자동 설치가 꺼져 있다. 검증용 빌드는 다음 명령으로 만든다.

```bat
build.bat clean candidate
```

결과는 `dist/candidate/AegisDesk`에 생성된다. 최종 승인 시험용 `released` 결과와 기본
`disabled` 결과도 별도 폴더를 사용한다. [설치 및 검증 절차](../guides/PPT_READER.md)를 따른다.
