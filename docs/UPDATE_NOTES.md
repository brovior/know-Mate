## 2026-07-28 (화)

- **엑셀 COM 경로 인덱싱 속도 개선**: 옛날 엑셀·DRM 문서를 오피스로 직접 열어 읽을 때 셀을 하나씩 읽던 것을 범위 단위(최대 1000행씩)로 한 번에 읽도록 바꿔, 큰 시트에서 인덱싱이 훨씬 빨라짐(검색 결과나 내용은 이전과 동일).
- **반복 실패하는 문서를 내부적으로 기록하기 시작함**: 특정 문서가 계속 인덱싱에 실패하면 원인 종류(점유 중/시간초과/손상·암호 등)와 연속 실패 횟수를 내부 기록 파일에 남김.
- **계속 실패하는 문서를 매번 다시 열지 않도록 함**: 위 기록을 바탕으로 실패 원인에 맞게 재시도 시점을 늦춤(점유 중이면 5~10분, 시간초과는 30분→6시간→24시간으로 점점 늘어남, 손상·암호 문서는 파일이 바뀌거나 수동 재인덱싱할 때까지 — 단 7일마다 한 번은 자동으로 재확인). 유휴 시간마다 반복되던 헛수고가 줄어 인덱싱 사이클이 빨라짐. 파일이 바뀌거나 사용자가 [인덱싱 시작]을 누르면 대기 없이 즉시 재시도됨 — 영구히 무시되는 파일은 없음.
- **[인덱싱 시작]/[재인덱싱]을 눌러도 계속 실패하는 문서의 실패 이력이 사라지지 않도록 수정**: 예전엔 버튼을 누르면 실패 기록 전체가 지워져, 며칠째 안 읽히던 DRM 문서까지 처음 상태로 되돌아가 30분 뒤 다시 열려고 시도하며 시간을 잡아먹었음 — 이제 이번 한 번만 다시 시도해보고, 또 실패하면 원래 대기 시간(최대 24시간/7일)으로 바로 돌아가 반복 낭비가 없어짐.
- **[확인 필요한 문서] 화면 추가**: 사이드바에 계속 실패하는 문서가 있으면 "⚠ 확인 필요한 문서 N건" 알림이 뜨고, 눌러보면 문서별로 실패 원인·횟수·다음 자동 재시도 시각을 확인할 수 있음. 문서별로 [지금 다시 시도](대기 없이 즉시 재시도)·[파일 위치 열기]·[인덱싱 제외](이 문서는 더 이상 검색 대상으로 삼지 않음, 언제든 해제 가능) 중 선택 가능.
- **원인 불명으로만 표시되던 반복 실패 문서의 원인이 더 자세히 구분되도록 개선**: "파일 열기"·"본문 읽기" 중 어느 단계에서 실패했는지 더 정확히 표시됨(예전엔 이 정보가 있어도 화면에 반영이 안 돼 대부분 "원인 미확인"으로만 보였음). 같은 문서가 같은 이유로 3번 이상 반복 실패하면 배지가 "조치 필요"로 바뀌어 눈에 띄게 표시되고, 재시도 간격도 30분→6시간→7일로 점점 늘어남(예전엔 최대 24시간까지만 늘었음). 단, 다른 사람이 열어둔 파일(사용 중)은 몇 번을 반복해도 5~10분 뒤 계속 재확인함 — 화면에는 "조치 필요"로 표시돼도 파일을 닫으면 곧 다시 시도됨.

## 2026-07-25 (토)

- **옛날 엑셀·워드 문서(.xls/.doc)가 한 번 실패하면 계속 실패하던 문제 해결**: 오피스가 문서를 열다 멈춰 강제 종료되면 "안전 모드로 시작할까요?" 안내창이 남아 다음 인덱싱도 똑같이 멈추는 악순환이 있었음 — 이제 그 흔적을 자동으로 정리하고, 문서를 열 때 확인창(읽기 전용 권장·손상 복구·암호 입력·인코딩 선택)이 아예 뜨지 않도록 바꿔 반복 실패가 사라짐
- **인덱싱이 사용자의 "최근 문서" 목록을 건드리지 않도록 수정**: 백그라운드로 읽은 파일이 엑셀·워드의 최근 문서 목록에 끼어들던 것을 막음
- **오래 켜둘수록 메모리가 1GB 가까이 쌓이던 문제 추가 수정**: 화면에 "문서 N개" 같은 건수를 표시하려고 유휴 자동 인덱싱이 돌 때마다(1분마다) 전체 문서 데이터베이스(검색용 벡터·암호화 본문 포함)를 통째로 메모리에 올렸던 것이 원인 — 이제 필요한 개수 정보만 가져오고, 변경된 파일이 없는 사이클은 아예 다시 세지 않도록 고침
- **인덱싱 중인 파일이 마침 그때 수정되면 옛 내용으로 저장돼 다시는 갱신 안 되던 문제 수정**: 이제 처리 도중 바뀐 게 감지되면 이번엔 건너뛰고 다음 번에 새 내용으로 다시 인덱싱함
- **엑셀·워드가 어느 단계(파일 열기/시트 조회/셀 읽기 등)에서 멈췄는지 로그로 구분 가능**: 문제 진단용 — 테스터가 직접 확인할 일은 없음

## 2026-07-23 (목)

- **배포판(exe)에서 날짜가 든 Excel 파일이 인덱싱 실패하던 문제 수정**: 빌드에 `win32timezone` 모듈이 빠져 `No module named win32timezone` 오류로 실패하던 것을 해결(다음 빌드부터 적용)
- **긴 인덱싱 도중 DRM 세션이 만료되는 경우 처리 개선**: "퇴근 전 [지금 재인덱싱]을 눌러두고 자리를 비운" 상황처럼 인덱싱이 오래 돌다 DRM 로그인 세션이 풀리면, 그 시점부터 DRM 보호 문서만 자동으로 건너뛰어(세션 유효한 다음 기회에 재시도) 인덱싱이 특정 파일에서 멈추지 않도록 함(이전엔 사이클 시작 시점에만 판정해 도중 만료를 놓쳤고, 수동 재인덱싱은 아예 적용되지 않았음)
- **트레이 [종료]가 프로세스를 확실히 끝내도록 수정**: 인덱싱 작업이 멈춰(행오버) 있을 때 [종료]를 눌러도 트레이 아이콘만 사라지고 프로그램이 백그라운드에 남아 PC가 버벅이던 문제를, 정상 종료가 안 되면 강제 종료하도록 보강해 해결
- **인덱싱이 특정 문서에서 멈추는 행오버 자동 복구**: Office 문서 열기/파싱이 멈추면(예: 세션 만료 후 DRM 로그인 대기) 파일 크기에 비례한 시간이 지난 뒤 해당 Office를 자동으로 정리해 그 파일만 실패 처리하고 인덱싱을 계속 진행 — 이전엔 한 파일에서 멈추면 그 뒤 전체가 멈췄음(300/1000에서 정지)
- **구형 xls 파일 처리 방식 개선**: 대부분의 `.xls` 파일을 이제 Office(Office 자동화) 없이 바로 읽도록 변경 — DRM으로 보호되거나 손상된 소수 파일만 예전처럼 Office를 통해 처리합니다. 정상 xls 인덱싱이 더 빠르고 안정적이며, 이번에 고친 행오버·좀비 프로세스·날짜 오류 문제 자체가 대부분의 xls에서 애초에 발생하지 않게 됩니다
- **긴 인덱싱 중 Office 안정성 개선**: doc/xls/ppt·DRM 문서를 COM(Office 자동화)으로 처리할 때, Office를 기본 30건마다 주기적으로 새로 띄우도록 해 오래 쓸수록 누적되는 메모리·핸들 문제로 후반부가 느려지거나 불안정해지는 것을 예방(설정에서 건수 조정·해제 가능)
